
### Explanation of Lua String Pattern Matching and Application to the Module

Lua's string pattern matching is a lightweight alternative to full regular expressions, using simple patterns with special characters prefixed by %. It's efficient for basic matching, searching, and replacing. Key functions include string.match, string.gmatch, string.find, and string.gsub.

#### How Lua Patterns Work

• Basic Syntax:
 • %a: Letters (A-Z, a-z)
 • %d: Digits (0-9)
 • %s: Whitespace
 • %w: Alphanumeric (letters, digits, underscore)
 • %p: Punctuation
 • .: Any character
 • *: Zero or more of the previous
 • +: One or more of the previous
 • ?: Zero or one of the previous
 • ^: Start of string
 • $: End of string
 • [abc]: Character class (a, b, or c)
 • (...): Capture group
• Differences from Regex: No lookaheads/lookbehinds, no non-greedy quantifiers, but faster and simpler for common tasks.
• Functions:
 • string.match(s, pattern): Returns the first match or captured groups.
 • string.gmatch(s, pattern): Iterator for all matches.
 • string.find(s, pattern): Returns start/end positions of the match.
 • string.gsub(s, pattern, repl): Replaces matches with repl.


#### Examples of Lua Pattern Matching

1. Matching a Valid Direction (as in your code):
local dir = "Left"
if dir:lower():match '^(left|right|up|down)$' then
  print("Valid direction")
end
-- Output: Valid direction
-- Explanation: ^ anchors to start, (left|right|up|down) is an alternation, $ to end. :lower() normalizes case.

2. Extracting a File Extension:
local file = "/path/to/script.lua"
local ext = file:match '%.(%w+)$'
print(ext)  -- Output: lua
-- Explanation: %. matches a literal dot, (%w+) captures the extension, $ ensures end of string.

3. Finding All Words in a String:
local text = "Hello world, this is Lua!"
for word in text:gmatch '%w+' do
  print(word)
end
-- Output: Hello, world, this, is, Lua
-- Explanation: %w+ matches sequences of alphanumeric characters.

4. Replacing Spaces with Underscores:
local str = "file name.txt"
local new_str = str:gsub('%s', '_')
print(new_str)  -- Output: file_name.txt B
