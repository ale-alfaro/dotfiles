## Tasks Overview

- Tasks can be defined in `mise.toml` or as file tasks.
- File tasks are preferred for better editor support and portability.
- Environment variables passed to tasks:
  - `MISE_ORIGINAL_CWD`
  - `MISE_CONFIG_ROOT`
  - `MISE_PROJECT_ROOT`
  - `MISE_TASK_NAME`
  - `MISE_TASK_DIR`
  - `MISE_TASK_FILE`
